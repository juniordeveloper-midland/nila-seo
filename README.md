# AIViz — Free MVP

A 100% free static demo of the AIViz AI visibility dashboard.

## Included
- Responsive SaaS UI
- URL input
- 25 sample prompts
- AI visibility dashboard
- Competitors
- Opportunities
- Reports
- Demo scan
- Downloadable report
- No API key
- No database
- No backend
- No paid hosting required

## Run locally
Open `index.html` in a browser.

## Free public hosting
Upload the three website files (`index.html`, `styles.css`, `app.js`) to a static host such as GitHub Pages. No paid license is required.

## Important
The numbers are sample/demo data. This version does not call AI providers or paid APIs. Real integrations can be added later.
